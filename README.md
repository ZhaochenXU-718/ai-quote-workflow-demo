# AI Quote Workflow Demo

A deterministic backend pipeline + evaluation harness for the
**manufacturing-export inquiry → quote** workflow: parse a customer inquiry,
match candidate products, retrieve supporting evidence, flag quotation risks,
generate clarification questions, and produce a controlled reply draft — with
risk rules kept as deterministic safety rails so the system never silently
over-commits on price, delivery, or certification.

This is an early demo of the direction described in the planning docs:

- [ai-startup-plan.md](ai-startup-plan.md) — business direction.
- [technical-feasibility-demo-architecture.md](technical-feasibility-demo-architecture.md) — feasibility & architecture.
- [plan.md](plan.md) — the P0–P7 build plan and current status.

## Requirements

- **Python 3.10+ recommended.** Runs on 3.9+ and uses **only the standard
  library** — no third-party packages to install. (Python 3.7/3.8 are
  end-of-life; upgrade before adding any typed-config, model-gateway, or web
  dependencies.)

There is nothing to `pip install`. Data resolution is anchored to the repository
root via `__file__`, so the commands below work from any working directory as
long as the repo root is on `PYTHONPATH` (running from the repo root is enough).

## Commands

Run from the repository root:

```bash
# P0 — validate the data contracts and print statistics
python3 -m backend.app.cli p0

# P1 — run the rule-based pipeline for one inquiry
python3 -m backend.app.cli run INQ-SYN-001

# P2 — evaluate the pipeline against gold answers
python3 -m backend.app.cli eval
python3 -m backend.app.cli eval --details         # full per-inquiry JSON

# Regenerate the synthetic dataset (leaves committed data byte-identical)
python3 scripts/generate_manufacturing_export_data.py
```

### Datasets

The same commands accept `--holdout` to target a hand-written generalization set
instead of the synthetic default:

```bash
python3 -m backend.app.cli p0 --holdout
python3 -m backend.app.cli eval --holdout
python3 -m backend.app.cli run INQ-HOLD-001 --holdout
```

- **default** — synthetic dev set generated by
  `scripts/generate_manufacturing_export_data.py`. Its gold shares the
  generator's logic, so its 100% scores are a **regression gate** only. The
  default `eval` must stay green.
- **holdout** — hand-written, human-labeled inquiries that the generator never
  produces (synonyms, units, inches, multilingual, etc.). It measures
  **generalization** and is expected to score lower; `eval --holdout` exits
  non-zero by design. See
  [eval/holdout/README.md](sample-data/manufacturing_export/eval/holdout/README.md).

## Layout

```text
backend/app/
  cli.py                 # command-line entry point
  data/loaders.py        # flat-file loaders (single CSV/JSONL/YAML parser)
  p0/validate_data.py    # data-contract validation
  p1/                    # rule-based extraction, candidate retrieval, risk checks
  p2/evaluate.py         # precision/recall/F1 evaluation harness
  p3/evidence_retriever.py  # lightweight citation/evidence retrieval
  p4/reply_generator.py  # controlled template-based reply drafts
sample-data/manufacturing_export/
  products/  inquiries/  templates/  rules/  eval/  eval/holdout/
scripts/
  generate_manufacturing_export_data.py  # reproducible synthetic-data generator
```

## Evaluation metrics

`eval` reports `precision`, `recall`, and `f1` for risk flags, product
candidates, and missing fields, plus false-positive counts. The pass gate
requires exact matches on risk flags and missing fields (no misses **and** no
false positives), because over-firing there means crying wolf or hallucinated
clarifications; product candidates are recall-gated only, since retrieval may
over-return for human review.

## Reply drafts

`run` output includes `reply_draft` with a customer-facing `subject` and `body`,
plus internal `supporting_citations`, `blocked_commitments`, and `safety_notes`.
The draft generator is template-based: it can ask for missing specs, flag
delivery/certification review, and cite candidate product evidence, but it does
not commit final price, delivery, certification, or final product selection.
